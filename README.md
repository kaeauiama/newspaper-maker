# 機関紙エディタ

縦組み・段組みの機関紙(A4・2〜4ページ)を作る、ブラウザで動く道具です。

**開く: https://kaeauiama.github.io/newspaper-maker/** (Chrome か Edge で)

- はじめての方は「見本を開く」で試せます(直したものは保存されません)
- 原稿・写真・紙名の設定は、あなたが選んだフォルダに保存します。このサイトに送られることはありません(すべてブラウザの中で処理します)
- PDF は「入稿」の画面から印刷の画面を開き、送信先を「PDF に保存」にして作ります。倍率や余白は変えません

## フォルダの形

「フォルダを開く」で選ぶのは、紙名の設定と号のフォルダが並んでいるフォルダです(以下では「機関紙フォルダ」と呼びます)。

```
機関紙フォルダ/             ← 「フォルダを開く」で選ぶのはここ
  publication.jsonc         紙名の設定(紙名・題字・PDF のファイル名・刷る前に確認していただく人)
  brand/                    題字の画像
  051/                      号のフォルダ(1号 = 1フォルダ)
    issue.jsonc             号の設定(号数・発行年月・配置・記事の順番)
    kiji1.txt …             記事の原稿(1記事1ファイル)、表の原稿
    photos/                 写真
    out/                    書き出したもの(入稿メモなど)
  052/
```

- はじめは空のフォルダを選べば、紙名の設定と号を画面で作れます。題字は、号の名前を押して出る「紙名と題字の設定…」で、画像・文字・線を置いて作ります
- `publication.jsonc`・`issue.jsonc`・`photos` の名前は変えないでください。号のフォルダの名前は自由ですが、号数の3桁(051 など)にしておくと順に並びます
- 新しい号は、号を選ぶ画面の「新しい号を作る」で作るか、前の号のフォルダを写して名前を変えます(写したら号数と発行年月を直す)
- 写真はスマホで撮った元の画像のまま入れてください。LINE などで送られて小さくなった写真は、印刷が粗くなります(画面で知らせます)
- 機関紙フォルダの1つ上のフォルダや、号のフォルダを選んでしまったときは、画面で知らせます

## 共有フォルダ(OneDrive・Google ドライブ)で使う

このサイトは OneDrive や Google ドライブに直接はつながりません(ウェブページから読み書きするには、サービスへのアプリの登録が要るため)。共有フォルダは、パソコンのフォルダとして開きます。

### 同期アプリのあるパソコン(自宅など)

1. OneDrive や Google ドライブ(パソコン版)で、機関紙フォルダをパソコンに同期します。人から共有されたフォルダは、自分の OneDrive・ドライブにショートカットを追加すると同期されます
2. 「フォルダを開く」で、同期しているフォルダの中の機関紙フォルダを選びます。次からは「前のフォルダを開く」で開けます
3. 保存すると、同期アプリがクラウドへ送ります。ほかのパソコンで作業する前に、送り終わっているか(同期アプリのアイコン)を確かめてください

### 同期アプリのないパソコン(共用のパソコンなど)

1. ブラウザで共有フォルダのリンクを開き、機関紙フォルダを「ダウンロード」します(zip になります)
2. zip を右クリックして「すべて展開」します
3. 「フォルダを開く」で、展開したフォルダの中の機関紙フォルダを選んで作業し、保存します
4. 終わったら、書き換えたファイルを共有フォルダの同じ場所へ送ります
    - 共有フォルダのページで号のフォルダ(051 など)を開き、パソコンの同じ号のフォルダの中のファイルをまとめてドラッグします。同じ名前のファイルは「置き換える」を選びます
    - 写真を足したときは、共有フォルダの `photos` を開いて、足した写真を送ります
    - 紙名や題字を直したときは、`publication.jsonc` と `brand` の中の画像も送ります
    - フォルダごとドラッグすると、Google ドライブでは同じ名前のフォルダがもう1つできてしまいます。フォルダの中へファイルを送ってください
5. パソコンに残った zip と展開したフォルダを消します

### 気をつけること

- 同じ号を2か所で同時に直さないでください。あとから送ったほうで上書きされます
- 「リンクを知っている全員が編集できる」共有は手軽ですが、リンクが漏れると誰でも中を見て書き換えられます。会員の名前や写真を置くなら、共有する相手を特定の人に限るか、リンクに有効期限やパスワードを付けてください(使える機能はサービスや契約によって違います)。リンクを人に見える所に貼らないでください
- 共用のパソコンでは、作業のあとでダウンロードしたものを消してください。「前のフォルダを開く」は、フォルダの場所を覚えているだけです(中身はブラウザに残りません)

## 必要なもの

- Chrome か Edge(Safari・Firefox では「フォルダを開く」が使えません)
- 紙面の書体は、使うパソコンに入っているものを使います(游明朝・游ゴシック、Office 付属の HG 書体)。Office の入っていないパソコンでは、見出しなどの書体が替わります

## このリポジトリについて

組み立てたものを置いているだけです(元のソースは別の場所で管理しています)。直接は書き換えません。
